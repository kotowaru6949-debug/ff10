# FF10 快適化ツール (FFX Comfort Tool)

Steam版 **FINAL FANTASY X/X-2 HD Remaster (`FFX.exe`)** 向けの、常駐型 Windows GUI 快適化トレーナーです。  
20GB超のゲームデータ (`data/FFX_Data.vbf`) や `FFX.exe` 本体のファイルは一切書き換えずに、実行中のプロセスメモリへリアルタイムで介入して動作します（ASLR対応・BaseAddress動的解決）。

---

## 主な機能

### Phase 1：ドロップ ＆ 盗む 快適化
- **アイテムドロップ率 100%**
- **装備ドロップ率 100%**
- **ドロップ装備 4スロット固定**
- **「盗む／ぶんどる」成功率 100%**（アイテムを持たない敵には通常通り「何も持っていない」）
- **同じ敵から何回でも100%盗める**（連続盗み時の確率減衰を無効化）
- **レア枠 ／ 通常枠 選択スイッチ**
  - `通常確率 (7/8・1/8)` / `レア枠 100%` / `通常枠 100%` の3モードを即時切替
- **ドロップ個数倍率**（`×1` / `×2` / `×4` / `×10` / `99個 (×99)`）
- **盗む個数倍率**（`×1` / `×2` / `×4` / `×10` / `99個 (×99)`）

### Phase 2：バトル・育成・収集 快適化
- **控えメンバーにもAP 100%分配（全員AP獲得）**
- **わいろ（Bribe）1ギルで100%成功＆最大個数**
- **モンスター捕獲 1回で10体（最大）カウント**
- **獲得AP倍率**（`×1` / `×2` / `×5` / `×10` / `×50` / `×100`）
- **獲得ギル倍率**（`×1` / `×2` / `×5` / `×10` / `×50` / `×100`）
- **バトル補助フラグ**
  - 常時「みやぶる（センサー）」表示
  - 常時オーバーキル (Overkill)
  - 常時クリティカル
  - 味方無敵 (Player Invincible)

### Phase 3：ワンクリック便利機能（セーブデータ即時編集）
※セーブデータをロードした状態で実行してください。
- **所持中アイテム全種 99個化**
- **所持ギル +1,000,000** / **所持ギル 999,999,999 (MAX)**
- **味方全員 S.Lv 99**
- **アルベド語辞書 全26巻コンプリート**
- **訓練場 全104種×10体捕獲済み**

## 使い方

1. `FFXComfortTool.exe` を起動します（Steam経由でゲームを管理者権限で起動している場合は、本ツールも「管理者として実行」してください）。
2. FF10 (`FFX.exe`) を起動すると自動的に接続され、上部に接続状態・PID・ベースアドレス・所持ギルが表示されます。
3. 必要なチェックボックスや倍率を操作するか、上部の **「快適セット ON」** ボタンで定番設定をまとめて有効化できます。

### グローバルホットキー（ゲーム画面のまま操作可能）
| キー | 操作 |
| :---: | :--- |
| **F5** | ドロップ100%＆盗む100%（4項目）一括 ON/OFF |
| **F6** | 枠選択切替（通常確率 → レア枠100% → 通常枠100%） |
| **F7** | 控えメンバーにもAP 100%分配 ON/OFF |
| **F8** | 常時オーバーキル ON/OFF |

## ビルド方法

Windows 標準の .NET Framework 4.0 C# コンパイラ (`csc.exe`) でビルドできます（追加SDK不要）。

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

## ファイル構成

- `src/FFXComfortTool.cs` : GUI・メモリパッチ本体ソースコード
- `build.ps1` : `csc.exe` ビルドスクリプト
- `FFXComfortTool.exe` : ビルド済み実行ファイル (x86)
- `.gitignore` : ゲーム本体ファイル (`data/`, `magicFiles/`, `*.vbf`, `FFX.exe` 等) の除外設定
