# FF10 / FF10-2 快適化ツール (FFX & FFX-2 Comfort Tool)

Steam版 **FINAL FANTASY X/X-2 HD Remaster（`FFX.exe` / `FFX-2.exe` 両対応）** 向けの、常駐型 Windows GUI 快適化トレーナーです。  
起動中のゲーム（FF10 / FF10-2）を自動判別してタブとメモリアドレスを切り替え、20GB超のゲームデータ（`.vbf`）や実行ファイル本体を一切改変せずに動作します（ASLR対応・BaseAddress動的解決）。

---

- **Phase 1：ドロップ ＆ 盗む 快適化**
  - **アイテムドロップ率 100%** / **装備ドロップ率 100%** / **ドロップ装備 4スロット固定**

  - **ドロップ個数倍率**・**盗む個数倍率**：`×1` / `×2` / `×4` / `×10` / `99個 (×99)`
- **Phase 2：バトル・育成・収集 快適化**
  - **控えメンバーにもAP 100%分配（全員AP獲得）**
  - **わいろ 1ギルで100%成功＆最大個数**
  - **モンスター捕獲 1回で10体（最大）カウント**
  - **獲得AP倍率**・**獲得ギル倍率**：`×1` / `×2` / `×5` / `×10` / `×50` / `×100`
  - **バトル補助フラグ**：常時「みやぶる（センサー）」、常時オーバーキル、常時クリティカル、味方無敵
- **Phase 3：ワンクリック便利機能（セーブデータ即時編集）**
  - 所持中アイテム全種 99個化 / 所持ギル +1,000,000・MAX / 味方全員 S.Lv 99 / アルベド語辞書 全26巻コンプ / 訓練場 全104種×10体捕獲済

## 使い方

1. `FFXComfortTool.exe` を起動します（ゲームを管理者権限で起動している場合は、本ツールも「管理者として実行」してください）。
2. `FFX.exe` または `FFX-2.exe` を起動すると自動接続し、対応するタブへ切り替わって設定を適用します。
3. 上部の **「快適セット ON」** ボタンで、その作品向けの定番快適設定をまとめて有効化できます。

### グローバルホットキー（ゲーム画面のまま操作可能）
| キー | FF10 動作 | FF10-2 動作 |
| :---: | :--- | :--- |
| **F5** | ドロップ100%＆盗む100% 一括 ON/OFF | ドロップ100%＆盗む100% 一括 ON/OFF |
| **F6** | 枠選択切替（通常 → レア100% → 通常100%） | 枠選択切替（通常 → レア100% → 通常100%） |
| **F7** | 控えメンバーにもAP 100%分配 ON/OFF | 常時「みやぶる（ライブラ）」ON/OFF |
| **F8** | 常時オーバーキル ON/OFF | 常時 99999 ダメージ ON/OFF |

## ビルド方法

Windows 標準の .NET Framework 4.0 C# コンパイラ (`csc.exe`) でビルドできます（追加SDK不要）。

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

## ファイル構成

- `src/FFXComfortTool.cs` : GUI・メモリパッチ本体ソースコード（FF10 / FF10-2 両対応）
- `build.ps1` : `csc.exe` ビルドスクリプト
- `FFXComfortTool.exe` : ビルド済み実行ファイル (x86)
- `.gitignore` : ゲーム本体ファイル (`data/`, `magicFiles/`, `*.vbf`, `FFX.exe`, `FFX-2.exe` 等) の除外設定
